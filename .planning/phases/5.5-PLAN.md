## 3. Work Breakdown & Implementation Tasks

### Wave 1: Error Diagnosis & Formal Report

#### Task 1: Generate Comprehensive Error Analysis Report
- **File:** `documentation/Error_Analysis_Report.md`
- **Actions:**
  1. Inspect every failed case in `data/results/PA_Test_Results.xlsx` and `data/test_runs/latest/cases/<Case_ID>.json`.
  2. Map each failure to exact criteria, patient records, and policy rules.
  3. Classify into root-cause buckets:
     - Policy-understanding / Boolean logic errors (9 cases)
     - Missing evidence / Hallucination errors (7 cases)
     - Clinical reasoning / Threshold errors (5 cases)
     - Conflict detection errors (4 cases)
  4. Write detailed diagnostic report detailing the failure mechanism, patient excerpt, policy rule, and prescribed hardening fix.

---

### Wave 2: Pipeline Hardening & Re-Evaluation

#### Task 2: Harden Stage 2 Clinical Determination Engine
- **File:** `scripts/run_pa_test_harness.py`
- **Actions:**
  1. Refactor Stage 2 determination prompt with strict clinical guardrails:
     - **Disjunctive Logic Guardrail:** Explicit instructions for *"at least N of M"* rules.
     - **Missing Evidence Guardrail:** Absolute prohibition against assuming tests occurred; enforce `UNKNOWN` if supporting doc is absent.
     - **Contradiction Cross-Checker:** Mandatory step explicitly comparing physician physical exam against radiology report; if contradictory, mandate `CONFLICT`.
     - **Boundary Guardrail:** Strict $\ge 6$ weeks conservative therapy requirement.
  2. Add `--cases` flag to `scripts/run_pa_test_harness.py` to allow targeted re-running of specific cases or full batch.

#### Task 3: Re-Execute Evaluation & Update Results
- **Actions:**
  1. Re-run the test harness across the cases with `--force`.
  2. Run `scripts/compare_test_results.py` to regenerate `data/results/PA_Test_Results.xlsx` and `data/results/metrics_summary.json`.
  3. Run `scripts/verify_results_workbook.py` to audit data integrity.
  4. Record before-and-after performance metrics in `documentation/Error_Analysis_Report.md`.
