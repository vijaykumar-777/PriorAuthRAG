# Phase 5.4 Plan: Automated Comparison Engine & Reporting Suite (`PA_Test_Results.xlsx`)

## 1. Executive Summary & Objective

Build and execute an automated evaluation and comparison engine (`scripts/compare_test_results.py`) that reconciles the 50 production-like test execution results in `data/test_runs/latest/system_run_results.json` against Ground Truth (`data/synthetic_cases/Synthetic_Test_Cases.xlsx` and `data/ground_truth/Policy_Ground_Truth.xlsx`).

The comparison engine will:
1. Reconcile overall PA determinations and criterion-level adjudications.
2. Generate the primary evaluation workbook `data/results/PA_Test_Results.xlsx` with three styled sheets (`Case_Level_Results`, `Criterion_Level_Results`, and `Summary_Metrics`).
3. Compute clinical evaluation metrics: Overall Accuracy, PA Determination Accuracy, Sensitivity, Specificity, False Positive Rate, False Negative Rate, Criterion Accuracy, and Citation Precision.
4. Export machine-readable metrics to `data/results/metrics_summary.json`.
5. Execute an automated verifier (`scripts/verify_results_workbook.py`) confirming 100% data integrity and checklist compliance.

## 3. Work Breakdown & Implementation Tasks

### Wave 1: Comparison Engine & Reporting Generation

#### Task 1: Build Automated Comparison Engine
- **File:** `scripts/compare_test_results.py`
- **Actions:**
  1. Ingest `data/test_runs/latest/system_run_results.json`.
  2. Ingest `data/synthetic_cases/Synthetic_Test_Cases.xlsx` (`Case_Level` and `Criterion_Level` sheets).
  3. Ingest `data/ground_truth/Policy_Ground_Truth.xlsx` (`Policy_Rules` sheet).
  4. Perform case-level comparison:
     - Compare `Ground Truth Overall Result` vs `System Overall Result`.
     - Assign `Overall PASS/FAIL`.
     - Capture runtime, test case type, and summary notes.
  5. Perform criterion-level alignment & comparison:
     - Map system criteria evaluations to ground truth `Criterion ID`s.
     - Compare `Ground Truth Criterion Result` vs `System Criterion Result`.
     - Assign `Criterion PASS/FAIL`.
     - Extract system evidence quotes, policy citations, and patient citations.
     - Tag errors using the standardized taxonomy (`RETRIEVAL_ERROR`, `CLINICAL_REASONING_ERROR`, etc.).
  6. Compute statistical metrics:
     - Total Cases, Passed Cases, Failed Cases.
     - Overall Accuracy = `Passed / Total`.
     - Sensitivity (True Positive Rate) = `TP / (TP + FN)`.
     - Specificity (True Negative Rate) = `TN / (TN + FP)`.
     - False Positives (over-approvals) and False Negatives (improper denials).
     - Criterion-level match accuracy.
     - Citation precision (percentage of evaluated criteria with valid page/section citations).
  7. Generate professional multi-sheet Excel workbook `data/results/PA_Test_Results.xlsx` using `openpyxl`:
     - Apply clean styling: frozen header panes, auto-adjusted column widths, color-coded PASS (soft green) and FAIL (soft red) conditional formatting.
     - Sheet 1: `Case_Level_Results`
     - Sheet 2: `Criterion_Level_Results`
     - Sheet 3: `Summary_Metrics`
  8. Save machine-readable `data/results/metrics_summary.json`.
